Le graphe Git

Une branche n'est qu'une étiquette posée sur un commit ; HEAD dit sur laquelle vous êtes. Cliquez les commandes et regardez l'historique pousser.

HEAD → branche → commit

Chaque cercle est un commit ; les étiquettes noires sont les branches ; l'étiquette rouge HEAD montre où vous êtes. Le prochain commit s'accroche au commit rouge.

État

Où pointe HEAD

Une branche est un pointeur vers un commit, pas une copie du projet : la créer ne coûte rien.

switch déplace HEAD ; commit fait avancer la branche de HEAD — et elle seule.

Terminal

merge

git switch main
git merge saut-double     # crée un commit de fusion

rebase puis merge

git switch saut-double
git rebase main           # rejoue les 2 commits
git switch main
git merge saut-double     # fast-forward

Même départ, mêmes commits, même contenu final : seule la forme de l'histoire change. En pointillés, les anciens commits réécrits par le rebase.

Merge

Garde l'histoire telle qu'elle s'est passée, avec ses bifurcations. Ajoute un commit de fusion. Sans danger sur une branche partagée.

Rebase

Réécrit l'histoire pour qu'elle soit linéaire, puis main avance en fast-forward. Plus lisible, mais les commits changent d'identité.

La règle

Rebase avant de proposer, sur une branche à vous seul. Merge pour intégrer.
