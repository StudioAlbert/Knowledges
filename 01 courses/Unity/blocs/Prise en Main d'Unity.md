# Prise en Main d'Unity

Ouvrir Unity pour la première fois et poser un projet propre : le dépôt Git adapté au moteur, l'interface de l'éditeur, et la brique de composition de base qu'est le prefab.

## Objectifs

- Créer un dépôt Git adapté à un projet Unity (`.gitattributes`, `.gitignore`, LFS)
- Naviguer dans le Hub et dans les fenêtres de l'éditeur
- Composer une scène à partir de prefabs et de leurs variantes
- Livrer un projet vide, propre et versionné
