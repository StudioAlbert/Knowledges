# Architecture et Design Patterns

Sortir du script monolithique : externaliser les données, encadrer les accès globaux, substituer des comportements, et relire son code à la lumière de SOLID.

## Objectifs

- Externaliser données et configuration en `ScriptableObject`
- Écrire un singleton générique, persistant et volontairement contraint
- Substituer un comportement à l'exécution avec le pattern Strategy
- Diagnostiquer un script Unity au regard des cinq principes SOLID
