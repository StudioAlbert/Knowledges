# Interface Utilisateur

Construire l'interface et la brancher au jeu, avec les deux systèmes que Unity fait cohabiter : uGUI et UI Toolkit.

## Objectifs

- Construire une interface avec le Canvas et ses composants
- Comparer uGUI et UI Toolkit, et savoir lequel choisir
- Composer une interface en flexbox (UXML / USS)
- Câbler l'interface au code de jeu dans les deux sens
