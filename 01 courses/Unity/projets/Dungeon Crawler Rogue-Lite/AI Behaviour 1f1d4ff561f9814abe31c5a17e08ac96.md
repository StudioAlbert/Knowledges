# AI Behaviour

### **AI Behaviour**

The aim is to create a set of NPCs (non-player characters). They 
should have different behaviour patterns and be able to change them 
according to their environment.

1/ Think about different behaviour patterns, e.g. :

- Chaser
- Dopelganger
- Patroller
- Shooter
- Guard
- or combination of these behaviours

2/ Set 3 differents types of ennemy, and also set differents situations combining these types :

- 1 Guard + 3 Patrollers
- 1 Dopelganger who can make chasers spawn
- etc..

3/ Set a room where you can trigger those differents sets of ennemies

### **Tips:**

- Pay more attention to believability and less to the scope of the game world.
- Think of a suitable scenario, e.g. zombie horde, alien swarm, flock of sheep, etc.
- Think of a suitable character to trigger the different behaviours.
- Use a suitable structure to manage the behaviours, e.g.
    - Finite state machineBehaviour Tree
- Think of plausible and comprehensible rules according to which the AI units act and react.
- Use a NavMesh for pathfinding of the AI units.
- Research suitable behaviours, how they work and how they have been implemented, in suitable games such as
    - Days Gone
    - Factorio
    - The Legend of Zelda: Breath of the Wild
    - *or from your own references*
