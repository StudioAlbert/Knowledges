# Versus Race Game - Micromachine Like

### Genre definition

> Le jeu vidéo de course en mode versus, similaire à Micromachines, appartient au genre de jeu de course multijoueur où les joueurs s'affrontent directement sur des circuits souvent miniatures et chaotiques. L'accent est mis sur la compétition rapide et intense entre les joueurs, avec des tracés sinueux et des obstacles originaux. Le jeu peut offrir une vue aérienne pour donner aux joueurs une perspective globale du parcours, favorisant ainsi des affrontements rapides et des manœuvres astucieuses.
Dans certaines versions, les joueurs s’affrontent dans des environnements domestiques (chambre, cuisine, etc.)
> 

### Features expected

- [ ]  Camera fixe, TOP-DOWN, permet de visualiser l’ensemble du parcours et des participants pendant toute la partie
- [ ]  Contrôles Joueur 1
    - [ ]  ZQSD, Fleches directionelles. Gauche/Droite pour faire pivoter le véhicule, avant/arrière pour accélérer / freiner
    - [ ]  CTRL Gauche pour un boost
    - [ ]  SPACE pour tir
- [ ]  Contrôles Joueur 2 : Manette
    - [ ]  D-Pad, Joystick G, Joystick D : Gauche/Droite pour faire pivoter le véhicule, avant/arrière pour accélérer / freiner
    - [ ]  Bouton B (EST) pour un boost
    - [ ]  Bouton 1 (Sud) pour Tir
- [ ]  4 véhicules avec des caractéristiques uniques, encourageant les joueurs à expérimenter différents styles de conduite.
- [ ]  **Power-Ups and Weapons:** Intégration d'armes ou de bonus spéciaux pour perturber les adversaires ou obtenir un avantage tactique.

### Experience content (Time / Levels)

- [ ]  5 à 10 minutes de temps de jeu
- [ ]  1 Parcours
