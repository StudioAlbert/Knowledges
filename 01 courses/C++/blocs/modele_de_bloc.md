# Modèle de bloc

Une phrase qui dit ce que le bloc couvre et dans quel ordre, sans lister les cours.

> Pour créer un vrai bloc : copier ce fichier dans `blocs/`, le renommer avec le
> nom du bloc (le nom de fichier **est** le nom référencé par la propriété `bloc`
> des cours), et passer `type: template` à `type: bloc`. Ne pas toucher au tableau
> ci-dessous : `python tools/sync_blocs.py` le remplit depuis les notes de cours.
