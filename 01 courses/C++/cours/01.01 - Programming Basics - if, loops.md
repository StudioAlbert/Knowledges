## Why use functions?
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

- Never copy-paste code
- Encapsulate routines
- Make your code more readable

```cpp
int compute_value(int a, int b) {
    return a + b;
}

int main() {
    int a = 12;
    int b = 42;
    std::cout << "compute_value: " << compute_value(a, b) << "\n";
    return 0;
}
```

## Pre-declaration
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Il se peut que vous ayez besoin de déclarer les fonctions à un autre endroit.

Comme dans le cas normal, vous déclarez juste la fonction avec un `;` à la fin.

```cpp
int compute_value(int a, int b);

int main() {
    int a = 12;
    int b = 42;
    return compute_value(a, b);
}

int compute_value(int a, int b) {
    return a + b;
}
```

## Functions syntax (BTW)
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

## If — le piège du `=`
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Vous pouvez utiliser un bloc pour faire plus d'une action, et un `else` pour faire un sinon.

```cpp
if (a == b) {
    a = 5;
} else {
    b = 6;
}

if (a = b) {  // valide, mais ça ne marchera PAS !
```

`=` est l'opérateur d'**assignement** : il transfère la valeur de `b` dans `a`, ce qui n'est PAS ce que l'on veut dans un `if`.

Donc si la valeur de `b` n'est pas 0, le `if` passera !

---

## If — la condition, c'est un entier
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Le check de condition est le suivant : si la valeur est **0**, c'est faux (`false`) ; sinon c'est vrai (`true`).

D'où le fameux :

```cpp
if (ptr) ...
```

---

## While
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
while (condition) {
```

- Condition can be anything that returns a value !
- `a = b` is valid — but `a == b` is what you mean, and this can make trouble
- The value is transformed into a `bool` : if `value == 0` then this is false, otherwise this is true
- As long as the condition is true, the loop will continue

---

## While — continue et break
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

- `continue` — go back to the beginning of the loop and do it again
- `break` — abort the loop and stop it

```cpp
while (a != b) {
    [...]
}
```

---

## Do … while
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
do { … } while (condition);
```

- Unliked by some (Stroustrup)
- Almost the same as a `while` loop
- The `while` is tested **at the end** of the first loop

---

## For — la boucle classique
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
for (statement; condition; statement) {
```

Like in Java and other languages derived from C, this is how a classic `for` loop is declared.

- the first statement is usually used to declare the values we're going to iterate
- the condition is the condition for the loop to continue
- the third statement is what happens at the end of the loop

---

## For — range-based
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
for (statement : initializer-list) {
```

This uses the `begin` and `end` of the class (or initializer list) behind the scenes, to make a classic `for` loop :

```cpp
for (auto it = initializer_list.begin(); it != initializer_list.end(); ++it)
```

---

## For — exemple
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

You can make a simple `for` this way :

```cpp
for (int i : {10, 12, 14, 16}) {
    i ...
}
```

This is the new style (C++11) of `for` loop.

## Switch
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
switch (value) {
    case value1:
        break;
    default:
        break;

```

- `[[fallthrough]]` in case you want to avoid using the `break` (C++17)
- Will switch according to `value`
