## What is an enum? — le problème
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
// set to 0 for "singleplayer", 1 for "deathmatch"
// and 2 for "capture the flag"
int gameMode = 0;

int main() {
    if (gameMode == 0) {
        puts("Starting a singleplayer game.");
    }
    else if (gameMode == 1) {
        puts("Starting a two player game.");
    }
    else if (gameMode == 2) {
        puts("Starting a four player game.");
    }
}
```

Note:
Tout est dans le commentaire : la signification des valeurs vit dans un
commentaire, pas dans le code. Rien n'empêche d'écrire `gameMode = 7`.
C'est exactement le trou que l'`enum` vient boucher.

```cpp
enum class Aliment

    PIZZA
};
```

---

## What is an enum?
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

A group of integer values, each with a name.

Useful when you describe a « **Type** » of something — example : a type of aliment.

```cpp
enum class Aliment
{
    BURGER,
    SUSHI,
    SALAD,
    PIZZA
};
```

## How is an enum useful?
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Cas d'usage typiques :

- status
- animation state
- animals
- colors

Pourquoi :

- more readable
- hiding complex values behind simpler ones
- a type more complex than an `int`, simpler than a class

---

## Plain enum vs enum class ?
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Avec un `enum` simple :

- two enumerations cannot share the same names
- no variable can have a name which is already in some enumeration
- enums are **not type-safe**

⇒ d'où l'usage systématique de `enum class` dans ce cours.

## C arrays
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
int x[6] = {19, 10, 8, 17, 9, 15};
```

- Arrays are **0 indexed** !
- Access to content with `operator[]` (read / write)

---

## Array can work with enums
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Astuce classique : la **dernière valeur de l'enum donne la taille du tableau**.

```cpp
enum class MonsterType { SKELETON, ZOMBIE, BAT, COUNT };

int monsterCount[static_cast<int>(MonsterType::COUNT)];
```

Note:
Le schéma d'origine était une image ; l'exemple ci-dessus illustre le
principe énoncé sur la diapo — ajouter un `COUNT` en fin d'énumération
pour dimensionner le tableau, ce qui garde les deux synchronisés quand on
ajoute un type.

---

## Passing an array to a function is passing by reference
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Un tableau C passé à une fonction **n'est pas copié** : la fonction reçoit l'adresse du premier élément. Toute modification faite dans la fonction est visible depuis l'appelant.

## C++ strings
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Strings are a class that can be included in any project by using the include :

```cpp
#include <string>
```

You can then use them through `std::string` :

```cpp
std::string greeting = "Hello world!";
```

---

## C++ concatenation
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

You can concatenate strings (meaning : add them) using the `+` sign :

```cpp
std::string first_name = "John";
std::string last_name  = "Doe";
std::string full_name  = first_name + " " + last_name;
std::cout << full_name;
```

---

## C++ concatenation — to_string()
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

If you want to add something that is NOT a string to a string, you can use the `std::to_string(...)` method :

```cpp
const int value = 3;
std::string apple_count = std::to_string(value) + " apples";
std::cout << "you have " << apple_count;
```

---

## C++ string length
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

How can you know the length of a string ?

```cpp
std::string txt = "here is something";
std::cout << "size: " << std::to_string(txt.length());
```

You can also use the `size` version of it (but watch out for Unicode !) :

```cpp
std::cout << "size: " << std::to_string(txt.size());
```

---

## C++ string access — operator []
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

How can you access what is inside a string ?

```cpp
std::string txt = "here is something";
char value = txt[3];
std::cout << "The character is [" << value << "]\n";
```

You can modify the string by using :

```cpp
txt[0] = 'J';
std::cout << txt;
```

---

## C++ string access — operator at()
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

Same as the `[]` operator.

Read :

```cpp
std::string txt = "here is something";
char value = txt.at(3);
std::cout << "The character is [" << value << "]\n";
```

Write :

```cpp
txt.at(0) = 'J';
std::cout << txt;
```

## String comparison — compare()
<!-- .slide: data-background="00 images/01_slide_fond_GP_22_08_22.jpg" -->

- returns **0** if both strings are equal
- returns a **positive** value if `str1 > str2`, or if the first unmatched letter of `str1` is greater than that of `str2`
- returns a **negative** value if `str1 < str2`, or if the first unmatched letter of `str1` is less than that of `str2`

```cpp
std::string str1("have apple");
std::string str2("have app");
std::cout << str1.compare(str2) << std::endl;
```
