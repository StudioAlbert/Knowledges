## Pointer on a function

### Exercice 1

Create two different functions that can divide floats and integers in two different processes:

- **integer division** — return an integer result of the division, rounded to the smallest value possible
- **float division** — return the exact division between two numbers
- use them to divide some numbers and check the result

### Exercice 2

Create a function `display(int)` that displays an int value in the console.

Create a function variable `ptrDisplay`.

Call that function through the variable.

### Exercice 3

Fill the gaps in the project:

- Code to display an integer value into the console in `callbackDisplay`
- In the `main`, connect the function pointer and the callback member in the class using the class methods
- Add some numbers into the class using the `add(int)` method

## Lambda expressions

### Exercice 4

Write a lambda expression to display an integer.

Write a lambda expression subtracting its parameter from a captured element.

Use the lambda expression inside a `for` loop.
