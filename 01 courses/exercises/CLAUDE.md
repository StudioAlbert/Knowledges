# Exercices

## Les exercices doivent être séparés en sujets

Si une séance touche plusieurs sujets, préciser le sujet dans le nom du fichier — un fichier
par sujet, `<CODE> - <Sujet>.md`. Le build les rattache à la séance par ce préfixe de code,
ou par `seances: [CODE, …]` en frontmatter.

Exemple, `GPR-CF-BDP-05` :

```
GPR-CF-BDP-05 - Énumérations.md
GPR-CF-BDP-05 - Tableaux.md
GPR-CF-BDP-05 - Bilan formatif, le morpion.md
```

Une séance sans fiche d'exercices est un cas courant, pas un oubli : le build se contente de
la compter dans son résumé.
