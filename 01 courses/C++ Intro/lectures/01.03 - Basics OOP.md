## Structures
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

A structure stores elements together.

```cpp
struct Enemy {
    std::string name;
    int hit_points;
    int defense;
    int attack;
}; // don't forget the ';'
```

---

## Structures — déclaration ≠ implémentation
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
Enemy alien{ "Xenomorphe", 100, 10, 10 };
```

… ou :

```cpp
Enemy alien;
alien.name       = "Xenomorphe";
alien.hit_points = 100;
alien.defense    = 10;
alien.attack     = 10;
```

- **Struct name** — le blueprint de la structure
- **Object name** — ce que l'on va réellement utiliser
- **Initializer list** — les valeurs doivent être données dans l'ordre, ou utiliser `.[name] = [value]` (C++17)

---

## Structures — utilisation
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
int player_hit_point = 100;
int player_attack = 10;

Enemy alien{ "Xenomorphe", 100, 10, 10 };

player_hit_point  -= alien.attack;
alien.hit_points  -= player_attack;

std::cout << "Alien hit points :" << alien.hit_points << "\n";
```

## Class
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

Actually the same as `struct` — except…

```cpp
class Enemy {
    std::string name;
    int hit_points;
    int attack;
    int defence;
};
```

By default, **everything is private**.

---

## Class — visibilité
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

You can change the visibility by using `public:`, `protected:`, `private:`.

- **public** — vous pouvez accéder à tout ce qui est à l'intérieur ; c'est ce qui explique que l'on accède à toutes les variables d'un `struct Enemy`
- **protected** — cas particulier, mais comme `private`, pas d'accès depuis l'extérieur
- **private** — interdit de voir ce qu'il y a à l'intérieur de la classe ou du struct

So what happens when you use `struct { private: … }` ?

---

## Class & struct
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

La seule différence entre une `class` et un `struct`, c'est **la visibilité par défaut**.

```cpp
struct [name] {
    /* public: */
    [...]
};

class [name] {
    /* private: */
    [...]
};
```

---

## Class and struct methods
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

You can associate a structure or a class with **methods**.

```cpp
class Animal {
    int food_ = 0;
public:
    void eat() {
        food_++;
    }
    void print() {
        std::cout << food_;
    }
};
```

- quand il y a des méthodes, on utilise généralement `class` plutôt que `struct` (les deux commencent par une majuscule)
- les `struct` servent aux agrégats sans méthode
- ici `food_` est un **membre** (suffixé par `_`)
- une méthode s'appelle aussi une **member function**

---

## Class and struct methods — usage
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
Animal lion;
lion.eat();
lion.eat();
lion.print();   // affiche 2
```

- une **classe** est une définition ! Elle n'a pas de réalité dans votre code : c'est le blueprint de ce que vous allez utiliser
- les **objets** sont des instances d'une classe : ils existent, ils sont là pour être appelés
- on appelle les méthodes d'une classe sur un objet (certaines méthodes peuvent être appelées sur la classe elle-même, on verra ça plus tard)

## Header et source

## Header
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
#pragma once
```

Remember, you could also use **guards** — this is actually the same thing, and it is present in a load of places :

```cpp
#ifndef MY_CLASS_NAME_H
#define MY_CLASS_NAME_H

[ the code ]

#endif // MY_CLASS_NAME_H
```

## Source

Ordre des includes, chaque groupe en ordre alphabétique :

1. source headers
2. C headers
3. STL (C++ headers)
4. other libs (boost, SDL, SFML, etc.)
5. project headers

## Classe — le duo .h / .cpp
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

**`my_class.h`**

```cpp
#pragma once

class MyClass {
public:
    int  myPublicAttribute;
    void MyPublicMethod();
private:
    int  myPrivateAttribute_;
    void MyPrivateMethod();
};
```

**`my_class.cpp`**

```cpp
#include "my_class.h"

#include <iostream>

void MyClass::MyPublicMethod() {
    std::cout << myPublicAttribute;
    std::cout << myPrivateAttribute_;
}

void MyClass::MyPrivateMethod() {
    std::cout << myPublicAttribute;
    std::cout << myPrivateAttribute_;
}
```

---

## Private VS public
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

```cpp
#include "my_class.h"

int main() {
    MyClass myClass{}; // myClass est une instance

    std::cout << myClass.myPublicAttribute << "\n";  // OK
    myClass.MyPublicMethod();                        // OK

    std::cout << myClass.myPrivateAttribute_ << "\n"; // ERREUR
    myClass.MyPrivateMethod();                        // ERREUR
}
```

Note:
Les deux dernières lignes sont le cœur de la diapo : elles ne compilent
pas. C'est exactement ce que l'on veut montrer — l'encapsulation se
constate à la compilation, pas à l'exécution.

---

## Private VS public — résumé
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

- **private** — accessible uniquement depuis l'intérieur de la classe ; donnée « sécurisée »
- **public** — accessible depuis l'intérieur et l'extérieur de la classe

---

## OOP — vocabulaire
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

| Terme | Définition |
|---|---|
| **Attribut, membre** | variable d'une classe |
| **Méthode** | fonction d'une classe |
| **Instance** | un objet d'une classe une fois instancié |
| **Classe** | description / modèle d'un objet |
| **Constructeur** | méthode qui initialise un objet |
| **Destructeur** | méthode qui détruit un objet |
| **Exposer** | rendre accessible un attribut privé par le biais d'une méthode publique |

## `this` = pointeur sur l'objet
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

**`Monster.h`**

```cpp
#pragma once

#include <iostream>

class Monster {
public:
    Monster();
    Monster(const int healthPoint);
    void PrintInfo();

private:
    int healthPoint_;
};
```

**`Monster.cpp`**

```cpp
#include "Monster.h"

Monster::Monster() {
    this->healthPoint_ = 50;
}

Monster::Monster(int healthPoints) : Monster() {
    this->healthPoint_ = healthPoints;
}

void Monster::PrintInfo() {
    std::cout << "Monster's health points : " << this->healthPoint_;
}
```

## Constructeur
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

- doit avoir **le même nom que la classe**
- on peut avoir plusieurs constructeurs avec différents paramètres (*overloading*)
- appelé **une fois** à l'initialisation de l'objet
- attention à la façon dont vous initialisez les valeurs dans un constructeur, surtout si ces attributs sont **constants** !

---

## Constructeur basique
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

**`monster.h`**

```cpp
#pragma once

#include <string>

class Monster
{
public:
    // Step 1 : Simple constructors, destructors
    Monster();
    ~Monster();

    void printInfo();

private:
    int health;
    int attack;
};
```

**`monster.cpp`**

```cpp
#include <iostream>
#include "Monster.h"

Monster::Monster()
{
    std::cout << "Monster born." << std::endl;
}

Monster::~Monster()
{
    std::cout << "Monster dead." << std::endl;
}

void Monster::printInfo()
{
    std::cout << "Health : " << this->health
              << " Attack : " << this->attack << std::endl;
}
```

**`main.cpp`**

```cpp
#include <iostream>
#include "Monster.h"

int main()
{
    Monster monsterA;
    monsterA.printInfo();
}
```

## Constructeur avec paramètres
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

**`monster.h`**

```cpp
#pragma once
#include <string>

class Monster
{
public:
    // Step 2 : Parameters
    Monster();
    Monster(int health_, int attack_);
    ~Monster();

    void printInfo();

private:
    int health;
    int attack;
};
```

**`monster.cpp`**

```cpp
Monster::Monster()
{
    std::cout << "Monster born." << std::endl;
}

Monster::Monster(int health_, int attack_):
    attack(attack_),
    health(health_)
{
    std::cout << "Monster born with parameters" << std::endl;
}

Monster::~Monster()
{
    std::cout << "Monster dead." << std::endl;
}
```

**`main.cpp`**

```cpp
#include <iostream>
#include "Monster.h"

int main()
{
    Monster monsterA;
    Monster monsterB(100, 100);

    monsterA.printInfo();
    monsterB.printInfo();
}
```

## Constructeur — valeurs par défaut
<!-- .slide: data-background="_images/01_slide_fond_GP_22_08_22.jpg" -->

**`monster.h`**

```cpp
class Monster
{
public:
    // Step 3 : Parameters and default values
    Monster(int health_ = 50, int attack_ = 50);
    ~Monster();

    void printInfo();

private:
    int health;
    int attack;
};
```

**`monster.cpp`**

```cpp
Monster::Monster(int health_, int attack_) :
    attack(attack_),
    health(health_)
{
    std::cout << "Monster born with parameters" << std::endl;
}

Monster::~Monster()
{
    std::cout << "Monster dead." << std::endl;
}

void Monster::printInfo()
{
    std::cout << "Health : " << this->health
              << " Attack : " << this->attack << std::endl;
}
```

**`main.cpp`** — inchangé : `Monster monsterA;` compile toujours, les défauts s'appliquent.

Note:
Avec les valeurs par défaut, un seul constructeur remplace les deux de
l'étape précédente. Attention : les valeurs par défaut se déclarent dans
le `.h`, pas dans le `.cpp`.
