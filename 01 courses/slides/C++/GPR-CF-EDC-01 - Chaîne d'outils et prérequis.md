## Prerequisites
<!-- .slide -->

1. **OS** — Windows (11, 10, 8.1, 7), Linux ou macOS
2. **Git**
3. **CMake** 3.12.4
4. **CLion**

---

## Install Git
<!-- .slide: data-background="00 images/01_slide_fond_titre.jpg" -->

Download on the Git website : [gitforwindows.org](https://gitforwindows.org/)

Launch the install, pick every default option, except those below :

- pick a text editor (Atom advised)
- pick « Use Windows' default console window »

---
## Install CMake
<!-- .slide: data-background="00 images/01_slide_fond_titre.jpg" -->

Download on the CMake website : [cmake.org/download](https://cmake.org/download/)

Launch the install, pick every default option, except those below :

- **add CMake to the system PATH**
- pick « Use Windows' default console window »

---
## Install Clion

Download Jetbrains toolbox : [Download Toolbox App](https://www.jetbrains.com/fr-fr/toolbox-app/)
- Check or create your account on JetBrains site : https://account.jetbrains.com/login
- On the first tab, you would see your licences.
