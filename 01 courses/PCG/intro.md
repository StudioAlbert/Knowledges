# Génération procédurale

Comment une machine fabrique du contenu de jeu à la place d'un level designer :
bruit et aléatoire contrôlé, graphes, automates cellulaires, `WaveFunctionCollapse`,
et ce que ces techniques coûtent réellement en production.

Le module est importé des supports Google Slides `00` → `03` du dossier
*Cours* Drive ; chaque note de `cours/` porte le lien vers son deck d'origine dans
`source_slides`. Le rapport d'import et les recouvrements avec les cours existants
sont dans [[02 Notes/Historique/2026-08-30 - import slides AI-PCG - doublons|la note d'import]].

Il suit la convention **Unity / C++** : un cours est une note de `cours/` avec sa
`duration_h`, et le tableau `## Cours` de chaque bloc est régénéré par
`tools/sync_blocs.py`.
