# TPS Adventure Game

## GamePlay reference

Create a game where the player can move around, open doors, and activate switch or enigmas to open the Final Gate and finish the game

Create a Third-person control for a character using a game engine. Implement basic abilities such as walking, running, jumping, looking around, etc..

Furthermore, all gameplay-relevant values for the control should be adjustable in the game engine without having to change the code directly.

### Features expected :

1. **Camera Perspective:** The player controls a character whose actions are viewed from a camera placed behind and slightly above or to the side of the character. This perspective allows players to see more of their character and the game world.
2. **Character Movement:** TPS games typically involve fluid character movement. Players can traverse the environment, dodge attacks, and perform various maneuvers to gain a tactical advantage during combat.

### Experience content (Time / Levels)

1. Winning condition : Exit from the map solving the enigmas, or the switches in order
2. Lose condition : No lose conditions

### Optional features

1. **Storytelling and Narrative:** Many TPS games feature strong narratives and character-driven stories. Players often engage in missions or campaigns that advance a plot, and they may interact with non-playable characters (NPCs) to uncover the game's storyline.

### Environnemental puzzle tips

<aside>
💡

**Environmental puzzles** in video games are challenges that require players to interact with and manipulate the game's environment to progress, often without direct instructions.  These puzzles are integrated into the world's design, using elements like levers, platforms, light, perspective, or movable objects to solve.

**The Witness** is a prime example, featuring over 650 puzzles where players must trace paths across grids or discover hidden paths in the environment by viewing them from specific angles.  These **environmental puzzles** (EPs) are scattered across the island and only become solvable when viewed correctly—such as when a ramp is moving or a boat is circling at a precise moment.

Other notable games with environmental puzzles include:

- **Half-Life: Opposing Forces**, where players must use a metal can to bridge a severed electrical cable and trigger a door.
- **Terranigma**, where players throw pots to break a door, relying on prior knowledge of object interaction.
- **Inside** and **Limbo**, which use environmental hazards, physics, and stealth to create atmospheric, logic-based challenges.
- **The Legend of Zelda: Breath of the Wild**, where players use physics, weather, and tools to solve puzzles in an open world.
- **Myst and Legend of Grimrock**, which rely on pressure plates, movable blocks, and hidden mechanisms.

These puzzles **emphasize observation, spatial reasoning, and contextual understanding**, making the environment itself the core mechanic of gameplay.

</aside>
