# Tower Defense

### Genre definition

> Le ***tower defense*** (souvent abrégée en **TD**) est un type de [jeu vidéo](https://fr.wikipedia.org/wiki/Jeu_vid%C3%A9o) où l’objectif est de défendre une zone contre des vagues successives d’ennemis se déplaçant suivant un itinéraire ou non, en construisant et en améliorant progressivement des tours défensives.

[https://fr.wikipedia.org/wiki/Tower_defense](https://fr.wikipedia.org/wiki/Tower_defense)
> 

### Features requises

- Camera Fixe
- Poser une tour parmi des slots fixes
- 1 chemin basique
    - 1 seul point de spawn
    - 1 seul objectif
    - 4 slots possibles
- Ennemies
    - 1 seul type d’ennemies sans capacité spécifique
    - Navigation via nav mesh
    - Systéme de vague : Faire spawn 10 ennemies
- UI
    - Compteur d’ennemies passés / d’ennemis restants
    - Menu Demarrer
    - Menu Pause / Quit

### Features optionnelles

- Plus de variétés dans les typologies d’ennemies
- Plus de variétés dans les typologie de tourelles
- Plus de variétés dans les typologies et systéme de vagues
- Ajout d’une économie
