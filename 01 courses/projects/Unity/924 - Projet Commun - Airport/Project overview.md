# Project overview

## Genre

Coopératif, multi-joueurs local

Overcooked dans un aéroport, mais un peu foufou.

## Gameplay

- Jeu coopératif
- Multi-joueur local : de 2 à 4 joueurs
- Physique clunky
- Les « clés du fun »
    - Coopération mise à rude épreuve
    - Objectifs loufoques
