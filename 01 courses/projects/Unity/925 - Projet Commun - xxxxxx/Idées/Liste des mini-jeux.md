# Liste des mini-jeux

Cette liste contient un résumé simple de chaque mini-jeu.

Pour une analyse plus profonde des fonctionnements des mini-jeux, veuillez vous référer au document [[01 courses/projects/Unity/924 - Projet Commun - Airport/GDD]].

| **Nom du mini-jeu** | **Description** | **Coopération** | **Schéma (whiteboard Confluence)** |
| --- | --- | --- | --- |
| **Douane** | Coopérez avec les autres joueurs afin d'assurer le bon fonctionnement de la douane. Pour s'y faire, travaillez les différents postes de sécurité :<br>• Détecter les valises suspicieuses grâce aux scanners<br>• Arrêtez les individus suspicieux<br>• Triez les valises dans les sections dont elles correspondent | *Oui* | [Whiteboard](https://sae-team-924.atlassian.net/wiki/spaces/PC/whiteboard/7831691) |
| **Tapis Roulant** | Individuellement, les joueurs doivent essayer de ramener des valises aux clients à qui elles appartiennent. Pour s'y faire, récupérez des valises du tapis roulant et d'après la couleur de la valise, la ramener au client dont la couleur correspond. (Possibilité de se battre pour récupérer les valises ?) | *Non* | [Whiteboard](https://sae-team-924.atlassian.net/wiki/spaces/PC/whiteboard/8585447) |
| **Embarquement** | Coopérez avec les autres joueurs pour compléter l'embarquement de l'avion. Pour s'y faire, chargez les valises qui vous sont données dans l'avion et faites embarquer les passagers à bord. | *Oui* | [Whiteboard](https://sae-team-924.atlassian.net/wiki/spaces/PC/whiteboard/7962671) |
| **Avion** | Coopérez avec les autres joueurs afin d'assurer le bon fonctionnement de l'avion sous peine de crasher. Pour s'y faire, gérez les nombreuses demandes que vous allez recevoir :<br>• Satisfaire les demandes (Nourriture, utilités…) des passagers (Normaux/VIP)<br>• Piloter ou réparer l'avion<br>Le mini-jeu se finit quand trop d'erreurs sont commises, il faudra alors récupérer un parachute et sauter de l'avion. | *Oui/Non* | [Whiteboard](https://sae-team-924.atlassian.net/wiki/spaces/PC/whiteboard/7536652) |
| **Valise Perdue** | Coopérez avec les autres joueurs pour essayer d'accéder aux valises perdues dans le hangar. Pour s'y faire, poussez ou tirez des boîtes afin de se frayer un chemin à travers ce puzzle. Certaines boîtes demandent plusieurs joueurs afin de pouvoir être déplacées. | *Oui* | [Whiteboard](https://sae-team-924.atlassian.net/wiki/spaces/PC/whiteboard/7536718) |
| **(Parachute)** | Individuellement, les joueurs doivent tenter de ne pas perdre de l'argent en évitant de rentrer en collision avec des débris pendant un certain temps. Pour s'y faire, contrôler un parachute et éviter les débris. Il est aussi possible de rentrer en collision avec d'autres joueurs afin de les pousser. | *Non* | [Whiteboard](https://sae-team-924.atlassian.net/wiki/spaces/PC/whiteboard/8552710) |
| **HUB** | Coopérez avec les autres joueurs pour entretenir le lobby afin de gagner du temps et des ressources pour les mini-jeux à venir. Pour s'y faire, il existe différentes tâches présentes que les joueurs peuvent effectuer :<br>• Serpillère<br>• Toilettes<br>• Poubelles<br>• Porte cassée<br>• Remplir snack<br>• Mettre à jour les vols<br>*Aucune explication précise pour ces mini-jeux n'existe* | *Oui* | [Whiteboard](https://sae-team-924.atlassian.net/wiki/spaces/PC/whiteboard/8519931) |
