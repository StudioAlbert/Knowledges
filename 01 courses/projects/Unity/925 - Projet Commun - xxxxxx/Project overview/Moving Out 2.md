# Moving Out 2

Players attempt to move items from one location to another while avoiding obstacles. It plays similarly to [*Moving Out*](https://en.wikipedia.org/wiki/Moving_Out_(video_game)) and includes elements of [strategy](https://en.wikipedia.org/wiki/Strategy_video_game), [puzzle](https://en.wikipedia.org/wiki/Puzzle_video_game), and [party video games](https://en.wikipedia.org/wiki/Party_video_games). Later [levels](https://en.wikipedia.org/wiki/Level_(video_games)) include additional environmental elements not found in the first game, such as one-way doors, teleporters, and time-limited passages. It features single-player and cooperative multiplayer, both online and local. Online multiplayer is a first for the series. It supports up to four players at once.

The game also supports a robust list of accessibility features. Similar to the original it has an assist mode which features enabling longer time limits, skipping levels after failing, reduced difficulty and objects disappearing on delivery, among others. Players can also change button mappings, user interface settings (such as font size and color) and disable certain repeating animations on levels to avoid motion sickness.
