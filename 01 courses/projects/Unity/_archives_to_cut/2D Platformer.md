### Genre definition

> A 2D platformer game is a type of video game that is characterized by its side-scrolling, two-dimensional graphical perspective and gameplay focused on navigating a protagonist through a series of levels or screens filled with platforms, obstacles, enemies, and challenges. 

The primary objective of the player is to control the character's movement, typically from left to right, and jump between platforms while avoiding hazards and defeating or outsmarting enemies to progress through the game. 

These games often require precise timing, skill, and coordination to overcome the various obstacles and complete levels.
> 

Create a 2D Jump'n'Run control for a character using the possibilities of a game engine. Implement basic abilities like walking, running & jumping. Furthermore, all gameplay-relevant values for the control should be adjustable in the game engine without having to change the code directly. This allows for flexible use and reuse of the controls for different scenarios.

### Features expected

- [ ]  The game character should be able to move horizontally
- [ ]  The game character shall use a 2D collider and a 2D rigidbody
- [ ]  **Jumping:** The game character shall be able to jump by pressing a button. Jumping is a fundamental mechanic in 2D platformers. Players need to time their jumps to reach higher platforms, cross gaps, and avoid hazards.
- [ ]  **Platforms:** These are flat or elevated surfaces the player character can walk, run, or jump on. They often come in various forms, including moving platforms, disappearing platforms, and more.
- [ ]  **Obstacles:** Games are filled with obstacles, traps, and challenges that the player must navigate. These may include spikes, bottomless pits, moving hazards, and more.
- [ ]  **Level design:** 2D platformer levels are carefully designed to create a sense of progression and challenge. They become progressively more difficult as the player advances through the game.
- [ ]  **Checkpoints:** Checkpoints are locations where the player can respawn if they lose a life, allowing them to avoid starting the level from the beginning.
- [ ]  **Scoring:** Many platformers feature a scoring system that rewards players for collecting items, defeating enemies, or completing levels quickly.

### *(i**t is mandatory to choose 2 options from the list below**)*

- [ ]  **Power-ups:** Collectible items or power-ups can enhance the player character's abilities. Common power-ups include extra lives, speed boosts, or special attacks.
- [ ]  **Enemies:** The game world is often populated with various types of enemies that the player must defeat or avoid. This adds a combat element to the gameplay.
- [ ]  Optional Jump mechanics :
    - [ ]  The game character can jump higher by holding down the jump key
    - [ ]  The character can still jump a few frames after leaving a platform and does not fall down immediately. This is called Coyote-Time in the technical jargon.
    - [ ]  If the jump key is pressed a few frames before the character touches the ground, this input should be saved and trigger a jump as soon as it touches the ground
    - [ ]  The character can jump off walls. This feature should be made selectable and deselectable in the engine
    - [ ]  The character can slide down walls. This property should be made selectable and deselectable in the engine
