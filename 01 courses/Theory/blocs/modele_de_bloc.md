# Modèle de bloc

Une phrase qui dit quelle notion théorique le bloc couvre et dans quel ordre.

> Pour créer un vrai bloc : copier ce fichier dans `blocs/`, le renommer avec le
> nom du bloc, et passer `type: template` à `type: bloc`.
>
> **Le tableau `## Cours` se tient à la main**, comme dans le vault GSDA : une
> ligne par heure de contenu, et `cours:` dans le frontmatter compte ces lignes.
> N'ajoute pas les marqueurs `<!-- cours:auto -->` : ils feraient reprendre le
> bloc par `tools/sync_blocs.py`, qui écraserait le tableau.
>
> La colonne `Source` renvoie vers la note de cours Unity ou C++ qui traite déjà
> la notion, ou `—` si le support reste à écrire.
