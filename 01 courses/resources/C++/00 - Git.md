## 5.0 — Formative

*Rendu Git.*

Créer un repository Git appelé `GPR4100.Ex.5.0`. N'oubliez pas d'inclure un `.gitignore` conçu pour le C++.

À l'intérieur, il faut faire un programme qui simule une partie de feuille — cailloux — ciseaux. Cette fois-ci, l'accent doit être mis sur un code propre, en utilisant tout ce qui a été vu en cours.

N'oubliez pas de créer un README et d'expliquer brièvement le programme.

## 5.1 — Formative

*Rendu Git.*

Un repository appelé `Ex5.1` ([github.com/Surue/Ex5.1](https://github.com/Surue/Ex5.1)) est à forker chez vous. Le lancer, faire en sorte qu'il compile, et compléter les parties manquantes indiquées dans le fichier `main.cpp`.

Toutes ces modifications doivent être faites sur une nouvelle branche créée à partir de `develop`, que vous nommez comme vous le voulez. Vous faites un commit pour chaque fonction complétée. Une fois l'exercice terminé, vous devez merger les modifications de votre branche sur `develop`.
