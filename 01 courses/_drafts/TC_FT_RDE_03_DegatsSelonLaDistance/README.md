# Les dégâts selon la distance — companion TC-FT-RDE-03

Le squelette du formatif de la séance *Fonctions et repères* : on entre une distance, le
programme affiche les dégâts. Les deux fonctions sont vides, c'est l'exercice.

| Étape | Ce qu'elle demande |
|---|---|
| `01_degats` | `DegatsProportionnels` puis `DegatsAmortis`, à écrire dans `src/degats.cc` |

## Compiler et lancer

```powershell
cmake -S . -B build
cmake --build build
```

Puis `build/01_degats/01_degats.exe`, et tapez une distance par ligne.

Énoncé complet : la feuille *Formatif — les dégâts selon la distance* du vault.

Conventions : voir `01 courses/companion projects/CLAUDE.md` et la skill `programmation-cpp`.
